# Babe — First Monthsary Website ❤️

This is a self-contained romantic website made for the first monthsary.

## What's included
- `index.html` — website
- `style.css` — design
- `script.js` — animations + music behavior
- `assets/first-photo.jpg` — your uploaded photo

## Important note about the song
The site embeds the official YouTube audio for **“Rearrange My World” by Daniel Caesar & Rex Orange County**. It attempts to autoplay, but modern browsers often block audible autoplay until the visitor interacts with the page. The “Our song” button is the fallback.

## Easiest way to publish it
### GitHub Pages
1. Create/sign in to a GitHub account.
2. Create a new public repository, e.g. `our-first-monthsary`.
3. Upload **all files and folders inside this package** (do not upload only the ZIP).
4. In the repository, open **Settings → Pages**.
5. Under “Build and deployment,” choose **Deploy from a branch**.
6. Choose the `main` branch and `/ (root)`, then save.
7. GitHub will give you a public `github.io` address. Send that link to Babe or turn it into a QR code.

### Netlify Drop
You can also drag the whole extracted folder into Netlify Drop to publish it quickly.

## Customization
The main personal content is already in `index.html`. You can replace the photo in `assets/first-photo.jpg` with another image if desired.
